# Digital Design & Fabrication Portfolio

Coursework portfolio from the **Digital Design and Fabrication** module,
part of the **Engineering of Socio-Technical Systems** program at
**Carl von Ossietzky University of Oldenburg**.

**Lecturers:** Prof. Dr. Susanne Boll-Westermann, Mikołaj Woźniak, Tobias Lunte

This repository documents eight hands-on exercises exploring electronics,
physical prototyping, and digital fabrication — from basic circuits and
Arduino-driven interactive systems to CNC milling, laser cutting, e-textiles,
CAD modelling, and 3D printing.

Each exercise folder contains its own README with the process, photos, code,
and reflection.

## Tools & Techniques

- **Electronics & prototyping:** Arduino Uno, breadboards, MOSFETs, sensors, actuators, pneumatic components
- **E-textiles:** sewable LEDs, conductive thread, coin-cell battery holders
- **CAD:** Inkscape, OnShape, Autodesk Fusion 360
- **Digital fabrication:** CNC milling, laser cutting & engraving (Epilog Fusion), FDM 3D printing (QIDI Q2, PLA Rapido)
- **Programming:** Arduino / C++
- **Workflow:** iterative prototyping, testing components individually before integration, hardware debugging
